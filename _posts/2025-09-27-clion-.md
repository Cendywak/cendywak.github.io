
# 快捷键

```bash
Alt + 1 #打开文件管理器
Shift双击 #快速搜索
Ctrl + N #搜索类
Ctrl + Shift +N #查找文件
Ctrl + Alt + Shift +N #查找方法或全局变量
Ctrl + Shit + A #搜索用法
Ctrl + Space #显示补全

#注释
Ctrl Shift / #注释代码块

Ctrl + W #逐级选择
Ctrl Shit W # 也是选择 不知道干嘛的

Ctrl Alt + T #使用if等包围代码段

Ctrl D #复制上一行
Shift + up #可以选择好几行

Alt + Shift + up/down #将当前行代码上下替换位置
Ctrl + Shift + up/down #上下移动方法

Ctrl -/= #折叠/展开代码
Ctrl Shift -/= #折叠/展开所有代码
Ctrl . #折叠所选代码，不知道为啥不起作用

#选择符号
Alt + J #选择光标处符号，可以多次点击
Alt + Shifr + J # 取消选择
Ctrl + Alt + Shifr + J # 选择所有匹配符号
#可以用这个实现快速替换

# 重命名

Ctrl P #方法签名？？

Ctrl Q #查看方法文档，第二次按下会弹出窗口
Ctrl F4 #关闭弹出窗口
Ctrl + Shifr + I #可以看代码定义？

#补全
Ctrl shift Space #智能类型补全？
Ctrl shift Enter 自动补全语句
#后缀补全

#查找
Ctrl shift f #在所有文件中查找，可以使用Alt + W 选择聚焦单词
Ctrl F #查找当前文件内容，使用Enter/F3 // Shift+F3 选择匹配项
Ctrl shift r #替換，可以使用Alt + P/M/D/Sf選擇作用範圍

Ctrl F12#查看文件结构，可以直接输入文字查找对应的内容 
Alt + 7 #嵌入的文件结构窗口

#编辑运行配置
```
